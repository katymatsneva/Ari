# Ari в Telegram — инструкция запуска

## Что умеет итоговая версия

- Айдентика «Слот»: логотип из дизайн-системы, графит и светлые фоны, коралл — мастера, мята — афиша, индиго — путешествия; Manrope, Noto Sans Armenian, IBM Plex Mono; голос на «ты», время и место первыми.

- Запись к мастерам и в салоны: к конкретному мастеру или к любому свободному.
- Карта «Рядом со мной» со свободными окнами и расстоянием; поиск «свободно сегодня вечером».
- Салоны: фото, команда по ссылке-приглашению, кабинет владельца и администратора, записи всей команды.
- Точка на карте, описание и фото входа, выбор карт для маршрута (Яндекс, 2ГИС, Google, Apple, такси).
- Афиша с фильтрами по датам и категориям, языки событий.
- Переписка клиента и мастера через бота, быстрые кнопки для ЧП.
- Отметки визитов, отзывы с отложенной публикацией и ответом мастера.
- Закреп «Мои записи» в чате с ботом, напоминания клиенту и мастеру.
- Подписка на записи в Google / Apple Календаре; импорт занятости из личного календаря мастера.
- Персональные ссылки и QR-коды мастеров и салонов, лист ожидания.
- Модерация новичков и событий, стоп-слова, жалобы, админка в боте, ежедневные бэкапы.

Займёт около часа. Программировать не нужно: создаёшь бота, загружаешь папку на GitHub и подключаешь хостинг.

## Что внутри

- `public/index.html` — само приложение, то же, что в прототипе, только данные хранятся на сервере.
- `server.js` — сервер: хранит записи, проверяет, что человек пришёл из Telegram, отправляет напоминания через бота.
- `seed.json` — демо-мастера и события для закрытого теста.
- `package.json` — список библиотек, хостинг установит их сам.

## Шаг 1. Создать бота

1. В Telegram найди **@BotFather** и нажми «Старт».
2. Отправь `/newbot`.
3. Имя бота: `Ari`.
4. Юзернейм должен заканчиваться на `bot`, например `ari_yerevan_bot`. Если занят, попробуй другой.
5. BotFather пришлёт **токен** — длинную строку вида `7412345678:AAH...`. Сохрани её. **Никому не показывай и не публикуй**: с токеном любой может управлять ботом.

По желанию там же: `/setuserpic` — аватар, `/setdescription` — текст, который человек видит до нажатия «Старт».

## Шаг 2. Загрузить код на GitHub

1. Зарегистрируйся на [github.com](https://github.com).
2. Нажми **New repository**, название `ari`, выбери **Private**, нажми **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
4. Распакуй архив и перетащи **всё содержимое папки** `ari-telegram` (файлы и папку `public`), не саму папку.
5. Внизу нажми **Commit changes**.

## Шаг 3. Запустить на хостинге Railway

Railway сам установит всё нужное и будет держать сервер включённым. Стоит около 5 $ в месяц — актуальную цену проверь на сайте. Названия кнопок иногда меняются, но логика та же.

1. Зайди на [railway.com](https://railway.com) → **Login** → **Login with GitHub**.
2. **New Project** → **Deploy from GitHub repo** → выбери `ari`.
3. Открой созданный сервис → вкладка **Variables** → добавь переменные:

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | токен из шага 1 |
| `TZ` | `Asia/Yerevan` |
| `NODE_ENV` | `production` |
| `DB_PATH` | `/data/ari.db` |
| `ADMIN_IDS` | твой Telegram ID (`771067861`) — модерация и панель `/admin` |

4. **Добавь хранилище**, иначе все записи будут пропадать при каждом обновлении: в проекте нажми **Create** (или правой кнопкой по сервису) → **Volume** → подключи к сервису с путём **`/data`**.
5. Вкладка **Settings** → раздел **Networking** → **Generate Domain**. Появится адрес вида `https://ari-production-xxxx.up.railway.app`.
6. Вернись в **Variables** и добавь `WEBAPP_URL` = этот адрес целиком, с `https://`.
7. Railway перезапустит сервер сам. Если нет — вкладка **Deployments** → **Redeploy**.
8. В **Settings** выбери регион в Европе, если есть выбор.

## Шаг 4. Проверить

1. Открой в браузере `адрес/health` — должно показать `{"ok":true}`.
2. Во вкладке **Deployments** → **View Logs** должны быть строки «Ari работает на порту…» и «Бот @… запущен».
3. В Telegram открой своего бота → **Старт** → **Открыть Ari**. Слева от поля ввода появится кнопка **Ari** — через неё приложение открывается всегда.

## Шаг 5. Тест вдвоём

Нужны два аккаунта Telegram — твой и подруги.

1. Подруга открывает бота, в приветствии выбирает «Я мастер» и заполняет страницу.
2. Ты находишь её в списке мастеров и записываешься на время через 25–30 часов.
3. У подруги в чате с ботом приходит «Новая запись».
4. Через несколько часов тебе придёт напоминание «Завтра в…» с кнопками «Буду / Перенести / Отменить». Нажми «Буду» — подруге придёт подтверждение.

Напоминания приходят за сутки и за 2 часа клиенту, за час мастеру, утром в 9:00 мастеру приходит план на день, а после визита клиент получает просьбу поставить оценку.

## Если что-то не так

| Что видишь | Что делать |
| --- | --- |
| «Откройте приложение через бота в Telegram» | Приложение открыто в обычном браузере. Открой через кнопку в боте |
| Бот молчит на «Старт» | Проверь `BOT_TOKEN` и логи. Токен должен быть без пробелов |
| После обновления пропали записи | Не подключено хранилище `/data` или неверный `DB_PATH` |
| В логах `409 Conflict` | Бот запущен в двух местах одновременно. Оставь один сервис |
| Кнопка «Открыть Ari» открывает пустой экран | Проверь `WEBAPP_URL`: адрес целиком, с `https://`, без пробела в конце |

## Обновление кода позже

Загружай на GitHub новые версии файлов (**Add file → Upload files → Commit changes**): `server.js`, `package.json`, `package-lock.json`, `seed.json`, `README.md` — в корень, `index.html` — внутрь папки `public`. Railway обновится сам за 1–2 минуты. База сохраняется, если подключено хранилище `/data`.

## Перед запуском для настоящих клиентов

- Удали демо-мастеров: убери переменную `SEED_DEMO` и добавь `CLEAR_DEMO` = `1`, после перезапуска убери и её.
- Реши с юристом, где должен стоять сервер: это вопрос о передаче персональных данных за границу. До этого тестируй только со знакомыми.
- Замени тексты документов на проверенные юристом.
- Онлайн-оплата подписки включится после регистрации ИП и подключения эквайринга — это следующий этап разработки.

## Как устроена защита данных

- Каждый запрос к серверу подписан Telegram — чужой человек не сможет подделать вход.
- Клиенты видят только свободное время мастера, без имён других клиентов.
- До согласия на обработку данных сервер ничего о человеке не сохраняет.
- «Удалить мои данные» в разделе «Документы» стирает профиль, отменяет будущие записи и обезличивает прошлые.
- Прошедшие записи старше года удаляются автоматически.
